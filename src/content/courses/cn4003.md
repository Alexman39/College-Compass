Καλώς ήρθατε στο μάθημα Web Technologies! Στην τάξη αυτή, θα εξερευνήσουμε τον
κόσμο των τεχνολογιών του Παγκόσμιου Ιστού (Web Technologies) και τον ρόλο που
παίζουν στη δημιουργία σύγχρονων, διαδραστικών και δυναμικών ιστοσελίδων και
εφαρμογών. Το Διαδίκτυο έχει γίνει αναπόσπαστο κομμάτι της καθημερινότητάς μας,
και οι τεχνολογίες που το υποστηρίζουν εξελίσσονται συνεχώς.

Κατά τη διάρκεια του εξαμήνου, θα καλύψουμε βασικές και προχωρημένες έννοιες
που σχετίζονται με την ανάπτυξη ιστοσελίδων, από τις θεμελιώδεις γλώσσες HTML,
CSS και JavaScript, μέχρι πιο προχωρημένες τεχνολογίες, όπως frameworks και
εργαλεία ανάπτυξης εφαρμογών Ιστού.

Το μάθημα θα περιλαμβάνει θεωρητικές διαλέξεις και πρακτικές ασκήσεις, ώστε να
αποκτήσουμε μια ισχυρή βάση και να αναπτύξουμε πραγματικά έργα. Επιπλέον, θα
εργαστούμε σε ένα μεγάλο project, το οποίο θα αποτελέσει μέρος της αξιολόγησής
μας. Σε αυτήν την εργασία, θα έχουμε την ευκαιρία να εφαρμόσουμε τις γνώσεις μας
και να δημιουργήσουμε μια πλήρη και λειτουργική διαδικτυακή εφαρμογή.

Ετοιμαστείτε για ένα συναρπαστικό ταξίδι στον κόσμο του Web Development, όπου οι
ιδέες σας θα μετατραπούν σε πραγματικές εφαρμογές!
