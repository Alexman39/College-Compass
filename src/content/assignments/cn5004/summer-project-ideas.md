Φτιάξτε προγράμματα (ιδανικά και με γραφικό περιβάλλον) για τα παρακάτω:

1. παιχνίδι Πέτρα-μολύβι-ψαλίδι-χαρτί
2. calculator με γραφικό κλπ.
3. μια προσομοίωση του πώς δουλεύει ένα ATM μιας τράπεζας
4. ένα server που να σου δίνει ένα RestFull API που θα φτιάξεις εσύ.
5. speech recognition δηλαδή να δείτε βιβλιοθήκες για AI κλπ. Αυτό ίσως αρχικά
   να το επιχειρούσατε να το κάνετε στη python πρώτα.
6. μια εφαρμογή για face detection χρησιμοποιώντας τη βιβλιοθήκη τησ OperCV.
7. OpenCV να πειραματιστείτε με image tracking και object detection.
8. Μετά από όλα τα παραπάνω αξίζει να δε το Java Spring Framework ιδίως αν
   θέλετε να δουλέψετε με Java.
