**Σενάριο:** Φανταστείτε ότι εργάζεστε για μια εταιρεία που αναπτύσσει λογισμικό
ηλεκτρονικού εμπορίου για πωλήσεις βιβλίων. Ο στόχος του λογισμικού είναι να
επιτρέπει στους χρήστες να πραγματοποιούν online αγορές, να περιηγούνται στον
κατάλογο και να λαμβάνουν προτάσεις βιβλίων.

## Οδηγίες

1. **Ανάλυση Απαιτήσεων:**
   - Καταγράψτε ένα σύνολο απαιτήσεων για την εφαρμογή ηλεκτρονικού εμπορίου.
     Προσπαθήστε να εντοπίσετε τις βασικές λειτουργικές και μη λειτουργικές
     απαιτήσεις, λαμβάνοντας υπόψη τα χαρακτηριστικά καλών απαιτήσεων που
     συζητήθηκαν στη διάλεξη (σαφήνεια, κατανοητότητα, συνοπτικότητα).
   - Για παράδειγμα, μια λειτουργική απαίτηση μπορεί να είναι: "Η εφαρμογή
     πρέπει να επιτρέπει στον χρήστη να προσθέτει βιβλία στο καλάθι αγορών του".
2. **Προτεραιοποίηση Απαιτήσεων με τη μέθοδο MoSCoW:**
   - Κατηγοριοποιήστε τις απαιτήσεις σε "Must" (Απαραίτητα), "Should" (Πρέπει),
     "Could" (Θα μπορούσαν), και "Won’t" (Δεν θα συμπεριληφθούν στην τρέχουσα
     έκδοση).
   - Αιτιολογήστε τις επιλογές σας. Για παράδειγμα, εξηγήστε γιατί η δυνατότητα
     "αναζήτησης βιβλίων με φίλτρα" είναι προτεραιότητα Must και όχι Could.
3. **Κατηγοριοποίηση Απαιτήσεων:**
   - Χρησιμοποιώντας την Ολιστική Μέθοδο ή τη μέθοδο FURPS+, κατηγοριοποιήστε τις
     απαιτήσεις σας σε Λειτουργικές, Μη Λειτουργικές, Απόδοσης, Συστήματος,
     Υλοποίησης.
   - Για παράδειγμα, μια μη λειτουργική απαίτηση απόδοσης μπορεί να είναι: "Η
     σελίδα του καταλόγου βιβλίων θα πρέπει να φορτώνει σε λιγότερο από 2
     δευτερόλεπτα για το 95% των χρηστών."
4. **Ανάλυση και Προτάσεις Βελτίωσης:**
   - Βάσει των χαρακτηριστικών των καλών απαιτήσεων, αναγνωρίστε τυχόν ασαφείς ή
     διφορούμενες απαιτήσεις. Προτείνετε τρόπους βελτίωσης ώστε να γίνουν πιο
     σαφείς και κατανοητές.

## Απαιτούμενη Υποβολή

- Ένα έγγραφο που περιέχει την ανάλυση των απαιτήσεων, την προτεραιοποίηση
  MoSCoW και την κατηγοριοποίησή τους.
- Σύντομη ανάλυση βελτίωσης για τυχόν ασαφείς απαιτήσεις.

Αυτή η άσκηση θα σας βοηθήσει να εφαρμόσετε τις έννοιες της Μηχανικής Απαιτήσεων
στην πράξη και να κατανοήσετε τη σημασία της σωστής ανάλυσης και διαχείρισης
απαιτήσεων κατά την ανάπτυξη λογισμικού
