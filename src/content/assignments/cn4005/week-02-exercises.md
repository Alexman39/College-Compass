1. Κατηγοριοποιήστε το λογισμικό και αναφέρετε συγκεκριμένα παραδείγματα στις
   εξής κατηγορίες: Λογισμικό Συστήματος, Λογισμικό Εφαρμογών, Λογισμικό
   Παραγωγικότητας, Επιστημονικό Λογισμικό, Λογισμικό Τεχνητής Νοημοσύνης,
   Ενσωματωμένο Λογισμικό. Μπορούν να αναζητήσουν παραδείγματα από την
   καθημερινή χρήση ή να χρησιμοποιήσουν δημοφιλείς εφαρμογές και τεχνολογίες.
2. Περιγράψτε τη δομή ενός Πληροφοριακού Συστήματος. Μπορείτε να επιλέξετε ένα
   παράδειγμα από έναν οργανισμό (π.χ. ένα σύστημα διαχείρισης βιβλιοθήκης ή ένα
   σύστημα ERP) και να περιγράψετε τα μέρη του, όπως δεδομένα, διαδικασίες,
   λογισμικό, και ανθρώπους.
3. Αναλύστε τα πλεονεκτήματα του κατανεμημένου ελέγχου έκδοσης (DVCS) όπως το
   Git, σε σύγκριση με τα κεντρικά συστήματα όπως το Subversion. Πότε θα επιλέγατε
   ένα DVCS και πότε ένα κεντρικό σύστημα;
4. Δημιουργία GitHub account. Σύνδεση και δημιουργία project. Χρήση του GitGUI σε
   Windows.
