## Ερωτήσεις

1. Ποιες είναι οι πιο κρίσιμες δραστηριότητες για την ολοκλήρωση του έργου;
2. Πώς μπορεί η αβεβαιότητα να επηρεάσει το χρονοδιάγραμμα του έργου;
3. Ποιες στρατηγικές μπορείτε να χρησιμοποιήσετε για να μειώσετε την αβεβαιότητα;
4. Ποιες ενέργειες μπορείτε να κάνετε για να διασφαλίσετε την ποιότητα της
   εφαρμογής;
5. Πώς μπορεί η ανατροφοδότηση χρηστών να επηρεάσει το τελικό προϊόν;

## Δυνατότητες στο Project Libre

- **Δημιουργία Διαγράμματος Gantt:** Μπορείτε να οπτικοποιήσετε το
  χρονοδιάγραμμα του έργου και την πρόοδο των δραστηριοτήτων.
- **Διαχείριση Πόρων:** Μπορείτε να αναθέσετε πόρους σε δραστηριότητες και να
  παρακολουθείτε τη χρήση τους.
- **Ανάλυση Κρίσιμου Μονοπατιού:** Θα μπορέσετε να προσδιορίσετε ποιες
  δραστηριότητες είναι κρίσιμες για την έγκαιρη ολοκλήρωση του έργου.
- **Αναφορές και Εκθέσεις:** Δημιουργία αναφορών για την πρόοδο, την κατανάλωση
  πόρων και την ανάλυση κινδύνου.
