### Β) Κύκλος Ζωής Ανάπτυξης Συστήματος- Waterfall & Agile (Βαθμός 25%)

**ΣΤΑΔΙΑ**

- **Προγραμματισμός Έργου (3)**
  1. Χρονοπρογραμματισμός Έργου
  2. Στελέχωση Έργου
  3. Κοστολόγηση ανάπτυξης και συντήρησης
- **Ανάλυση (2)**
  1. Συλλογή πληροφοριών (συνεντεύξεις/συνεργασία με πελάτη)
  2. Αποτύπωση σκοπού, ανάλυση λειτουργικών αναγκών
- **Σχεδίαση Δικτυακού Τόπου (2)**
  1. Σχεδιασμός αρχιτεκτονικής (Hardware/Software)
  2. Σχεδιασμός εικαστικού θέματος και δομής
- **Υλοποίηση/Ανάπτυξη Δικτυακού Τόπου (8)**
  1. Εγκατάσταση λογισμικού στον Web Server
  2. Παραμετροποίηση Web Server (Hosting)
  3. Ανάπτυξη Δικτυακού Τόπου (δομή, σελίδες, μενού)
  4. Καταχώρηση περιεχομένου (κείμενα, γραφικά, εικόνες, κ.α.)
  5. Κλειστή Δημοσίευση και δοκιμές λειτουργίας
  6. Διορθώσεις επί των αποτελεσμάτων της πιλοτικής λειτουργίας
  7. Εκπαίδευση Διαχειριστών
  8. Εκπαίδευση απλών χρηστών
- **Υποστήριξη (1)**
  1. Παρακολούθηση, συντήρηση και τεχνική υποστήριξη έργου

**Ερωτήσεις/Δραστηριότητες**

1. Δημιουργήστε ένα αρχείο ProjectLibre (ή MS Project) και εισάγετε κάτω από το
   στάδιο/δραστηριότητα **Προγραμματισμός Έργου** τις 3 (υπο)δραστηριότητες
   (διάρκειες 5,1,1).

   Αναπροσαρμόστε τη στήλη Predecessors (**θυμηθείτε ότι κάνετε χρήση του
   μοντέλου Καταρράκτη**). Στο σημείο αυτό θα πρέπει να έχετε το ακόλουθο πλάνο:
   *(στιγμιότυπο του πλάνου στο πρωτότυπο έγγραφο, στο Moodle)*

   Συμπληρώστε και τις υπόλοιπες υποδραστηριότητες στο αρχείο ProjectLibre (ή MS
   Project) συμπληρώνοντας κατάλληλα τους predecessors και εισάγετε ένα
   screenshot εδώ.
2. Δείτε το ακόλουθο πλάνο. Η ημερομηνία έναρξης του σταδίου Ανάλυσης ορίστηκε
   μετά το τέλος του Χρονοπρογραμματισμού Έργου. *(στιγμιότυπο του πλάνου στο
   πρωτότυπο έγγραφο, στο Moodle)*

   Α) Μπορεί να γίνει αυτό; Αν ναι, υπό ποιες προϋποθέσεις; Για ποιο μοντέλο θα
   πρόκειται τότε;

   Β) Περιγράψτε αναλυτικά μια διαφορετική προσέγγιση με Agile και πως θα ήταν η
   αντίστοιχη ανάλυση σε scrum user stories (πχ δημιουργήστε πίνακα) με σειρά
   προτεραιότητας και story points.

## ΕΡΓΑΣΙΑ MEΡΟΣ B’ (30%)

### Παρουσίαση (Project Pitching) – Βαθμός 30%

3. Η Εταιρεία λογισμικού για την οποία εργάζεστε σας στέλνει να κάνετε μια
   παρουσίαση της πρότασης υλοποίησης της Εταιρείας στους υπεύθυνους του Δήμου
   Έδεσσας.
4. Θα πρέπει να προετοιμάσετε μια παρουσίαση σε Powerpoint (15-20 διαφάνειες),
   όπου θα παρουσιάζετε την δική σας πρόταση υλοποίησης που μπορεί και να είναι
   όχι μόνο μια (δηλαδή να προτείνετε τα υπέρ και τα κατά δύο ή περισσοτέρων
   προσέγγισεων).
5. Ο Στόχος σας θα είναι να πείσετε τους υπεύθυνους του Δήμου ότι επικυρώνοντας
   το Έργο υπέρ σας, βρίσκονται σε ασφαλή χέρια καθώς έχετε την ΚΑΛΥΤΕΡΗ
   ΠΡΟΤΑΣΗ!
6. Η παρουσίαση των διαφανειών θα γίνει μέσα στην Τάξη και στον κάθε φοιτητή θα
   δοθεί ένα 15λεπτο.
