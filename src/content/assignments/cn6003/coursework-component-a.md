## Σκοπός

Η εργασία αποσκοπεί στην ανάπτυξη γνώσεων και πρακτικών δεξιοτήτων για τη
λειτουργία, τη χρηστικότητα και την αποτελεσματικότητα εργαλείων ασφάλειας
δικτύων. Μελετάς και συγκρίνεις λογισμικά εργαλεία που προστατεύουν
υπολογιστικά συστήματα και δίκτυα από απειλές και επιθέσεις.

Η εργασία είναι ατομική. Η αναφορά πρέπει να είναι αποκλειστικά δική σου
δουλειά και όλες οι πηγές να αναφέρονται σωστά στη βιβλιογραφία. Αν δεν
περάσεις στην πρώτη εξεταστική, στη δεύτερη ευκαιρία (καλοκαίρι) μπορείς να
υποβάλεις την ίδια εργασία, με τις απαραίτητες διορθώσεις και βελτιώσεις.

### Μαθησιακοί στόχοι που αξιολογούνται

1. Να συγκρίνεις εργαλεία και τεχνικές προστασίας συστημάτων και δικτύων από
   εισβολές και να επιλέγεις τα κατάλληλα για συγκεκριμένες εισβολές.
2. Να εκπονείς ερευνητικό έργο μεσαίας κλίμακας και να ερμηνεύεις τα ευρήματά
   σου, από βιβλιογραφία ή από πειράματα σε ασφαλές περιβάλλον (virtual
   machines).
3. Να παρουσιάζεις τα αποτελέσματα σε μορφή γραπτής αναφοράς.
4. Να αξιολογείς εργαλεία λογισμικού απέναντι στις απαιτήσεις της σύγχρονης
   ασφάλειας πληροφοριακών συστημάτων.
5. Να αναγνωρίζεις τα εργαλεία και τις τεχνικές των hackers / crackers και
   τους τύπους επιθέσεων που εξαπολύονται με αυτά.

## Κατηγορίες εργαλείων

Τα δύο εργαλεία πρέπει να ανήκουν στην **ίδια κατηγορία** και να τρέχουν σε
Windows, MS-DOS, PowerShell ή Kali Linux (σε εικονική μηχανή). Για εργαλεία
εκτός των παρακάτω κατηγοριών χρειάζεσαι πρώτα την έγκριση του καθηγητή.

| Κατηγορία | Ενδεικτικά εργαλεία | Ενδεικτικά μετρήσιμα κριτήρια σύγκρισης |
| --- | --- | --- |
| Cryptographic Tools / Applications | OpenSSL, GnuPG (GPG) | Υποστηριζόμενοι αλγόριθμοι, χρόνος κρυπτογράφησης και αποκρυπτογράφησης αρχείων, παραγωγή και διαχείριση κλειδιών, δημιουργία και επαλήθευση ψηφιακών υπογραφών, ευχρηστία CLI και scripting |
| Steganography / Data Hiding | Steghide, OpenStego | Υποστηριζόμενες μορφές αρχείων κάλυψης, μέγιστη χωρητικότητα payload, ποιότητα αρχείου μέσω PSNR ή SSIM, κρυπτογράφηση του payload, ευκολία ενσωμάτωσης και εξαγωγής |
| Digital Forensics Tools | Autopsy, The Sleuth Kit, FTK | Υποστήριξη συστημάτων αρχείων, ταχύτητα αναζήτησης λέξεων-κλειδιών, πληρότητα εξαγωγής τεκμηρίων, δημιουργία αναφορών, ευχρηστία GUI ή CLI, αναπαραγωγιμότητα |
| Vulnerability Scanners | Nikto, OpenVAS / Greenbone, Sn1per, Qualys VMDR | Εύρος κάλυψης, ακρίβεια και ψευδώς θετικά, χρόνος σάρωσης, λεπτομέρεια αναφορών και μορφές εξαγωγής, χρήση CPU και RAM |
| Network Protocol Analysers | Wireshark, ManageEngine NetFlow Analyzer, TShark, Colasoft Capsa | Κάλυψη αποκωδικοποίησης πρωτοκόλλων, ευελιξία φίλτρων, εξαγωγή και αυτοματοποίηση, χρήση πόρων σε μεγάλα PCAP, εξαγωγή artefacts |
| Multipurpose Sniffers / Content Filters | Wireshark, tcpdump / Free Network Analyzer | Real-time capture, ποσοστό απώλειας πακέτων, φιλτράρισμα περιεχομένου, απόδοση σε αυξημένη κίνηση, αποθήκευση και επανάληψη captures |
| Firewalls / Antivirus / Anti-theft / Anti-spam | McAfee, ZoneAlarm, ClamAV | Αποτελεσματικότητα πολιτικών αποκλεισμού, επίδραση στο throughput, δημιουργία και διαχείριση κανόνων, ψευδώς θετικά, logging και alerting |
| Password Checkers / Managers | KeePass, Bitwarden, LastPass, Dashlane | Μορφή αποθήκευσης και ισχύς κρυπτογράφησης, εισαγωγή και εξαγωγή δεδομένων, εντροπία παραγόμενων κωδικών, ευχρηστία και συγχρονισμός, ανάκτηση και αντίγραφα ασφαλείας |
| DAI (Dynamic ARP Inspection) | arpwatch, static ARP με κανόνες iptables, Juniper Junos Space Network Security Manager | Ανίχνευση ARP spoofing, χρόνος έως την ειδοποίηση, ψευδώς θετικά σε δυναμικό LAN, ευκολία ανάπτυξης, ενσωμάτωση με δικτυακές συσκευές ή logs |
| Encryption Tools VPN / TLS | OpenVPN, OpenSSL TLS test server/client | Πολυπλοκότητα και χρόνος εγκατάστασης, διαχείριση κλειδιών και πιστοποιητικών, throughput με κρυπτογράφηση, cipher suites, συμβατότητα με clients και πλατφόρμες |
| Port Scanners | Nmap, Masscan | Ταχύτητα σάρωσης, ακρίβεια εντοπισμού θυρών, service και version detection, χρήση CPU και RAM, μορφές εξόδου, ενσωμάτωση με scripts |
| Password Crackers | John the Ripper, Hashcat | Τύποι hashes, ταχύτητα cracking, ποσοστό επιτυχίας με τυπικά wordlists, rules και GPU acceleration, ευκολία χρήσης και τεκμηρίωση |
| Man in the Middle (MITM) Tools | Bettercap, mitmproxy, Ettercap | Ποσοστό επιτυχίας υποκλοπής, καθυστέρηση που προστίθεται, διαχείριση πιστοποιητικών, καταγραφή ροών, πόσο εύκολα ανιχνεύεται |
| Intrusion Detection Systems (IDS / IPS) | Snort, Suricata | Ποσοστό ανίχνευσης, ψευδώς θετικά, throughput και χρήση CPU, δημιουργία κανόνων, μορφές alerts και logs, multi-threading |

> **Σημείωση:** στην εκφώνηση τα **PSNR** και **SSIM** εμφανίζονται και ως
> «εργαλεία» στην κατηγορία Cryptographic Tools. Δεν είναι εργαλεία
> κρυπτογραφίας αλλά **μετρικές ποιότητας εικόνας**, και ανήκουν στα κριτήρια
> της στεγανογραφίας (πόσο αλλοιώνεται η εικόνα κάλυψης). Γι' αυτό στον πίνακα
> εδώ εμφανίζονται μόνο εκεί.

Κάποια από αυτά τα εργαλεία τα έχουμε ήδη δει στις σημειώσεις: το **Nmap** στις
[Εβδομάδες 2](../../week/2/) και [6](../../week/6/), το **Wireshark** στις
[Εβδομάδες 4](../../week/4/) και [6](../../week/6/), το **OpenSSL** στην
[Εβδομάδα 2](../../week/2/), και τα **John the Ripper** και **Ettercap** στην
[Εβδομάδα 6](../../week/6/).

## Παραδοτέα

Διαλέγεις **μία κατηγορία** και συγκρίνεις **δύο εργαλεία του ίδιου τύπου** με
σαφή και μετρήσιμα κριτήρια. Τα δύο εργαλεία πρέπει:

- να είναι του ίδιου τύπου, ώστε η σύγκριση να είναι ισότιμη·
- να ανήκουν σε μία από τις παραπάνω κατηγορίες (αλλιώς χρειάζεται προηγούμενη
  έγκριση)·
- να έχουν εγκριθεί από τον καθηγητή **πριν** την τελική υλοποίηση·
- να μπορούν να παρουσιαστούν στο εργαστήριο σε έως **15 λεπτά**, με
  **15–20 διαφάνειες PowerPoint**.

Η τελική υποβολή είναι μια **ακαδημαϊκή αναφορά τουλάχιστον 2.500 λέξεων** με
τις εξής ενότητες:

1. **Περιγραφή των εργαλείων.** Σύντομη αλλά ουσιαστική περιγραφή των δύο
   εργαλείων: σκοπός, βασικές λειτουργίες, πεδίο εφαρμογής.
2. **Κριτήρια σύγκρισης και πειραματική διαδικασία.** Τα μετρήσιμα κριτήρια που
   χρησιμοποίησες. Για κάθε εργαλείο ένα παράδειγμα εφαρμογής με
   **screenshots που δείχνουν timestamp και ολόκληρη την οθόνη σου**.
3. **Αποτελέσματα και συγκριτική αξιολόγηση.** Τα αποτελέσματα ανά κριτήριο,
   για παράδειγμα σε πίνακα τριών στηλών (δες παρακάτω), και μια γενική
   αποτίμηση: ποιο εργαλείο προτείνεις και γιατί, με βάση τα αποτελέσματα.
4. **Μελέτη περίπτωσης.** Ένα σενάριο όπου εφαρμόζεται το εργαλείο: βασικά
   στοιχεία της εφαρμογής, τεκμηριωμένα βήματα και εικόνες από την εκτέλεση.
5. **Παραπομπές και βιβλιογραφία.** Πλήρης λίστα με τις πηγές που χρησιμοποίησες
   για να κατανοήσεις τα εργαλεία, να επιλέξεις τα κριτήρια και να τεκμηριώσεις
   τα συμπεράσματα.

Χρειάζονται **τουλάχιστον δέκα screenshots ανά εργαλείο**: ουσιαστικά,
ευανάγνωστα και να καλύπτουν τα κριτήρια σύγκρισης.

## Κριτήρια αξιολόγησης

Η εργασία βαθμολογείται με άριστα το 100.

| Κριτήριο | Βαρύτητα | Τι κοιτάζει |
| --- | --- | --- |
| Βάθος έρευνας | 20% | Ποικίλες και αξιόπιστες πηγές: βιβλία, επιστημονικά άρθρα, τεχνική τεκμηρίωση, επίσημες πηγές των κατασκευαστών. Η βιβλιογραφία δείχνει καθαρά ποιες πηγές χρησιμοποιήθηκαν. |
| Επίπεδο κατανόησης | 20% | Ουσιαστική κατανόηση του πώς λειτουργούν τα εργαλεία· σύνδεση της θεωρίας με την πράξη· σαφής σκοπός και ρόλος της κατηγορίας εργαλείων. |
| Ποιότητα συγκριτικής αξιολόγησης | 40% | Σχετικά, λογικά και μετρήσιμα κριτήρια· και τα δύο εργαλεία αξιολογούνται με συνέπεια στα ίδια κριτήρια· τα συμπεράσματα δείχνουν πλεονεκτήματα, περιορισμούς και καταλληλότητα του καθενός. |
| Ποιότητα / παρουσίαση της αναφοράς | 20% | Όλα τα απαιτούμενα στοιχεία· επαγγελματική και ακαδημαϊκά ορθή δομή, γλώσσα, βιβλιογραφία και μορφοποίηση. |
| **Σύνολο** | **100%** | |

Η σύγκριση μετράει τα **40%**: εκεί κρίνεται η εργασία. Διάλεξε κριτήρια που
μπορείς πραγματικά να μετρήσεις στο εργαστήριό σου (χρόνος, ποσοστά, χρήση
πόρων) και μέτρησέ τα με τον ίδιο τρόπο και στα δύο εργαλεία.
