Ένα πρόγραμμα σπάνια κάνει πάντα το ίδιο. Ανάλογα με τα δεδομένα, παίρνει
**αποφάσεις**: αν ο βαθμός είναι πάνω από 50 τυπώνει «PASS», αλλιώς «FAIL». Μια
**συνθήκη** είναι μια έκφραση που βγαίνει `true` ή `false`, και το πρόγραμμα
ακολουθεί τον έναν ή τον άλλον δρόμο.

## if και else

```java
int score = 62;

if (score >= 50) {
    System.out.println("PASS");
} else {
    System.out.println("FAIL");
}
```

Αν η συνθήκη στην παρένθεση είναι `true`, εκτελείται το πρώτο μπλοκ· αλλιώς το
μπλοκ του `else`. Η ίδια απόφαση μπορεί να γραφτεί και ανάποδα
(`if (score < 50)` → «FAIL»): το αποτέλεσμα είναι ίδιο, αρκεί οι δύο κλάδοι να
αντιστοιχούν σωστά.

## else if: πολλές περιπτώσεις

Όταν οι περιπτώσεις είναι περισσότερες από δύο, οι συνθήκες ελέγχονται **με τη
σειρά**, και εκτελείται **μόνο** η πρώτη που ισχύει:

```java
int score = 84;
char grade;

if (score >= 90) {
    grade = 'A';
} else if (score >= 80) {
    grade = 'B';
} else if (score >= 70) {
    grade = 'C';
} else if (score >= 60) {
    grade = 'D';
} else if (score >= 50) {
    grade = 'E';
} else {
    grade = 'F';
}
System.out.println("Βαθμός: " + grade);   // Βαθμός: B
```

Η σειρά έχει σημασία. Αν έβαζες πρώτα το `score >= 50`, κάθε βαθμός πάνω από
50 θα έπαιρνε «E», γιατί αυτή θα ήταν η πρώτη συνθήκη που ισχύει.

## switch

Όταν συγκρίνεις **μία** μεταβλητή με πολλές συγκεκριμένες τιμές, το `switch` είναι
πιο καθαρό από πολλά `else if`:

```java
int month = 3;

switch (month) {
    case 12:
    case 1:
    case 2:
        System.out.println("Χειμώνας");
        break;
    case 3:
    case 4:
    case 5:
        System.out.println("Άνοιξη");
        break;
    default:
        System.out.println("Άλλη εποχή");
}
```

- Κάθε `case` είναι μια πιθανή τιμή. Πολλά `case` στη σειρά μοιράζονται τον ίδιο
  κώδικα.
- Το **`break`** σταματά το `switch`. Αν το ξεχάσεις, η εκτέλεση συνεχίζει
  («πέφτει») και στο επόμενο `case`.
- Το `default` εκτελείται όταν δεν ταιριάζει κανένα `case`.
- Δουλεύει με `int`, `char`, `String` και μερικούς ακόμα τύπους, όχι όμως με
  `double` ή `boolean`.

### switch expression

Από τη Java 14, το `switch` μπορεί να **επιστρέφει τιμή**, με τη σύνταξη `->`.
Δεν χρειάζεται `break`, και ο μεταγλωττιστής σε αναγκάζει να καλύψεις όλες τις
περιπτώσεις:

```java
int day = 6;

String type = switch (day) {
    case 1, 2, 3, 4, 5 -> "Καθημερινή";
    case 6, 7 -> "Σαββατοκύριακο";
    default -> "Λάθος ημέρα";
};
System.out.println(type);   // Σαββατοκύριακο
```

## try, catch, finally: όταν κάτι πάει στραβά

Κάποια λάθη εμφανίζονται μόνο όταν τρέχει το πρόγραμμα: διαίρεση ακεραίου με το
μηδέν, ή κείμενο που δεν είναι αριθμός. Η Java τα λέει **εξαιρέσεις**
(*exceptions*). Αν δεν τις χειριστείς, το πρόγραμμα σταματά απότομα. Με το
`try-catch` μπορείς να αντιδράσεις «ευγενικά»:

```java
String input = "δώδεκα";

try {
    int number = Integer.parseInt(input);   // εδώ μπορεί να γίνει λάθος
    System.out.println("Ο αριθμός είναι " + number);
} catch (NumberFormatException e) {
    System.out.println("Σφάλμα: αυτό δεν είναι αριθμός.");
} finally {
    System.out.println("Τέλος ελέγχου.");
}
```

```text
Σφάλμα: αυτό δεν είναι αριθμός.
Τέλος ελέγχου.
```

- **`try`:** ο κώδικας που μπορεί να «πετάξει» εξαίρεση. Μόλις γίνει το λάθος, η
  εκτέλεση πηδά κατευθείαν στο `catch`.
- **`catch`:** χειρίζεται τη συγκεκριμένη εξαίρεση, π.χ. τυπώνει ένα μήνυμα.
  Μπορείς να έχεις πολλά `catch`, ένα για κάθε είδος λάθους.
- **`finally`:** εκτελείται **πάντα**, είτε έγινε λάθος είτε όχι. Χρησιμεύει για
  «καθάρισμα», π.χ. για να κλείσεις ένα αρχείο. Είναι προαιρετικό.

Δύο συνηθισμένες εξαιρέσεις:

| Εξαίρεση | Πότε | Παράδειγμα |
| --- | --- | --- |
| `ArithmeticException` | διαίρεση ακεραίου με το 0 | `10 / 0` |
| `NumberFormatException` | μετατροπή κειμένου που δεν είναι αριθμός | `Integer.parseInt("abc")` |

```java
try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Δεν γίνεται διαίρεση με το μηδέν.");
} catch (NumberFormatException e) {
    System.out.println("Λάθος μορφή αριθμού.");
}
```

Μόνο η διαίρεση **ακεραίων** με το 0 πετάει εξαίρεση. Το `10.0 / 0` δεν
πετάει: δίνει `Infinity`.

## Ερωτήσεις αυτοαξιολόγησης

<details>
<summary>1. Τι τυπώνει το παράδειγμα με το else if για score = 95; Και για score = 45;</summary>

Για 95 τυπώνει «Βαθμός: A», γιατί η πρώτη συνθήκη (`score >= 90`) ισχύει. Για
45 καμία συνθήκη δεν ισχύει, οπότε εκτελείται το `else`: «Βαθμός: F».

</details>

<details>
<summary>2. Τι γίνεται αν στο switch των εποχών λείπει το break μετά το «Χειμώνας» και month = 1;</summary>

Τυπώνεται «Χειμώνας» και μετά «Άνοιξη», γιατί η εκτέλεση συνεχίζει στο επόμενο
`case` μέχρι να βρει `break` ή το τέλος του `switch`.

</details>

<details>
<summary>3. Γιατί χρησιμοποιούμε try-catch αντί να αφήσουμε το πρόγραμμα να σταματήσει;</summary>

Για να αντιδράσει το πρόγραμμα με τρόπο ελεγχόμενο, π.χ. να εξηγήσει στον
χρήστη τι έγινε ή να του ζητήσει ξανά είσοδο, αντί να κλείσει απότομα με ένα
μήνυμα σφάλματος που δεν καταλαβαίνει.

</details>

<details>
<summary>4. Πότε εκτελείται το μπλοκ finally;</summary>

Πάντα: και όταν ο κώδικας του `try` τελειώσει κανονικά, και όταν γίνει
εξαίρεση και εκτελεστεί ένα `catch`.

</details>

```java
String result = switch (letter) {
    case 'A', 'B' -> "Σωστό";
```
