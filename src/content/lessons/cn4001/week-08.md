## Στατικές μέθοδοι

Ας πούμε ότι πρέπει να υπολογίσεις το εμβαδό πολλών κύκλων. Αντί να γράφεις τον
τύπο ξανά και ξανά, τον γράφεις **μία φορά** σε μια μέθοδο και την **καλείς**
όσες φορές θέλεις:

```java
public class Geometry {

    // Δέχεται την ακτίνα, επιστρέφει το εμβαδό.
    public static double circleArea(double radius) {
        return Math.PI * radius * radius;
    }

    public static void main(String[] args) {
        System.out.printf("%.2f%n", circleArea(1.0));   // 3.14
        System.out.printf("%.2f%n", circleArea(2.5));   // 19.63
    }
}
```

Η επικεφαλίδα `public static double circleArea(double radius)` λέει:

- **`static`:** η μέθοδος ανήκει στην κλάση, οπότε την καλείς χωρίς να φτιάξεις
  αντικείμενο.
- **`double`:** ο **τύπος επιστροφής**· με `return` στέλνεις πίσω το αποτέλεσμα.
  Αν μια μέθοδος δεν επιστρέφει τίποτα, γράφεις `void`.
- **`circleArea`:** το όνομα, συνήθως ρήμα ή περιγραφή του τι κάνει.
- **`(double radius)`:** οι **παράμετροι**, οι τιμές που δέχεται. Όταν την καλείς,
  δίνεις τα **ορίσματα**, π.χ. `circleArea(2.5)`.

Μια μέθοδος μπορεί να δέχεται και πίνακα:

```java
public static double average(int[] values) {
    int sum = 0;
    for (int v : values) {
        sum += v;
    }
    return (double) sum / values.length;
}
```

Τα κέρδη είναι ότι γράφεις κάτι **μία φορά** και το χρησιμοποιείς πολλές, ο
κώδικας **διαβάζεται** πιο εύκολα, και αν βρεις λάθος, το διορθώνεις σε **ένα**
σημείο.

## Αντικειμενοστραφής προγραμματισμός

Ο **αντικειμενοστραφής προγραμματισμός** (*OOP*) οργανώνει το πρόγραμμα γύρω από
**αντικείμενα**. Κάθε αντικείμενο αντιστοιχεί σε κάτι πραγματικό (έναν φοιτητή,
ένα προϊόν, ένα αυτοκίνητο) και έχει **δεδομένα** (ιδιότητες) και
**συμπεριφορά** (μεθόδους). Στηρίζεται σε τέσσερις αρχές:

| Αρχή | Τι σημαίνει |
| --- | --- |
| **Ενθυλάκωση** (*encapsulation*) | τα δεδομένα ενός αντικειμένου είναι κρυμμένα, και αλλάζουν μόνο μέσα από τις μεθόδους του |
| **Αφαίρεση** (*abstraction*) | φαίνονται μόνο όσα χρειάζεται ο χρήστης· οι λεπτομέρειες μένουν κρυφές |
| **Κληρονομικότητα** (*inheritance*) | μια κλάση-παιδί παίρνει τις ιδιότητες και τις μεθόδους μιας κλάσης-γονέα |
| **Πολυμορφισμός** (*polymorphism*) | αντικείμενα διαφορετικών κλάσεων χρησιμοποιούνται με τον ίδιο τρόπο, μέσω της κοινής τους κλάσης-γονέα |

## Κλάσεις και αντικείμενα

Μια **κλάση** είναι το **καλούπι**· ένα **αντικείμενο** είναι κάτι που φτιάχνεις
από αυτό το καλούπι, με τις δικές του τιμές.

```java
public class Book {
    // Ιδιότητες: κάθε βιβλίο έχει τις δικές του τιμές.
    private String title;
    private int pages;

    // Κατασκευαστής: εκτελείται όταν φτιάχνεις ένα νέο βιβλίο.
    public Book(String title, int pages) {
        this.title = title;
        this.pages = pages;
    }

    // Μέθοδοι: τι μπορεί να κάνει ένα βιβλίο.
    public boolean isLong() {
        return pages > 400;
    }

    public void printDetails() {
        System.out.println(title + " (" + pages + " σελίδες)");
    }
}
```

```java
public class Main {
    public static void main(String[] args) {
        Book a = new Book("Οδύσσεια", 560);
        Book b = new Book("Ο μικρός πρίγκιπας", 96);

        a.printDetails();              // Οδύσσεια (560 σελίδες)
        System.out.println(b.isLong()); // false
    }
}
```

- Οι **ιδιότητες** (`title`, `pages`) είναι μεταβλητές που ανήκουν σε κάθε
  αντικείμενο χωριστά. Το βιβλίο `a` και το βιβλίο `b` έχουν διαφορετικές τιμές.
- Ο **κατασκευαστής** (*constructor*) έχει το ίδιο όνομα με την κλάση και κανέναν
  τύπο επιστροφής. Ορίζει τις αρχικές τιμές όταν γράφεις `new Book(...)`.
- Το **`this`** σημαίνει «αυτό το αντικείμενο». Στο `this.title = title`
  ξεχωρίζει την ιδιότητα από την παράμετρο που έχει το ίδιο όνομα.
- Οι μέθοδοι **δεν** είναι `static`: καλούνται πάνω σε ένα συγκεκριμένο
  αντικείμενο, π.χ. `a.printDetails()`, και χρησιμοποιούν τα δικά του δεδομένα.

### Ενθυλάκωση με private, getters και setters

Επειδή οι ιδιότητες είναι **`private`**, κανείς έξω από την κλάση δεν μπορεί να
γράψει `a.pages = -5`. Αν χρειάζεται πρόσβαση, η κλάση δίνει μεθόδους που
ελέγχουν τι επιτρέπεται:

```java
public int getPages() {
    return pages;
}

public void setPages(int pages) {
    if (pages > 0) {           // δεχόμαστε μόνο λογικές τιμές
        this.pages = pages;
    }
}
```

Έτσι η κλάση προστατεύει τα δεδομένα της. Αυτό είναι η **ενθυλάκωση**.

## Ερωτήσεις αυτοαξιολόγησης

<details>
<summary>1. Τι σημαίνει ότι μια μέθοδος είναι void;</summary>

Ότι δεν επιστρέφει τιμή. Κάνει κάτι, π.χ. τυπώνει, αλλά δεν στέλνει αποτέλεσμα
πίσω σε όποιον την κάλεσε.

</details>

<details>
<summary>2. Ποια είναι η διαφορά ανάμεσα σε κλάση και αντικείμενο;</summary>

Η κλάση είναι το σχέδιο: ορίζει ποιες ιδιότητες και μεθόδους υπάρχουν. Το
αντικείμενο είναι ένα συγκεκριμένο «κομμάτι» φτιαγμένο από αυτό το σχέδιο, με τις
δικές του τιμές.

</details>

<details>
<summary>3. Γιατί ο κατασκευαστής δεν έχει τύπο επιστροφής;</summary>

Γιατί δεν τον καλείς για να πάρεις μια τιμή, αλλά για να αρχικοποιήσει ένα νέο
αντικείμενο. Το `new` είναι αυτό που επιστρέφει το αντικείμενο.

</details>

<details>
<summary>4. Τι κερδίζεις κάνοντας τις ιδιότητες private και δίνοντας setters;</summary>

Ελέγχεις ποιες τιμές επιτρέπονται, π.χ. αρνητικές σελίδες απορρίπτονται. Επίσης,
μπορείς να αλλάξεις τον εσωτερικό τρόπο αποθήκευσης χωρίς να επηρεαστεί ο κώδικας
που χρησιμοποιεί την κλάση.

</details>

<details>
<summary>5. Γράψε μια στατική μέθοδο max που δέχεται δύο ακέραιους και επιστρέφει τον μεγαλύτερο.</summary>

```java
public static int max(int a, int b) {
    return a > b ? a : b;
}
```

</details>
