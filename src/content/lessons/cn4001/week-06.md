Ένας **βρόχος** (*loop*) επαναλαμβάνει ένα κομμάτι κώδικα όσο ισχύει μια
συνθήκη. Έτσι, αντί να γράψεις την ίδια εντολή δέκα φορές, τη γράφεις μία φορά
και λες στον υπολογιστή πόσες φορές να την κάνει. Η Java έχει τέσσερα είδη
βρόχων:

| Βρόχος | Πότε τον διαλέγεις |
| --- | --- |
| `for` | όταν **ξέρεις** πόσες επαναλήψεις θέλεις |
| `while` | όταν ο αριθμός των επαναλήψεων εξαρτάται από μια συνθήκη |
| `do-while` | όπως ο `while`, αλλά το σώμα εκτελείται **τουλάχιστον μία φορά** |
| enhanced `for` | για να περάσεις από όλα τα στοιχεία ενός πίνακα, χωρίς μετρητή |

## Ο βρόχος for

```java
int sum = 0;
for (int i = 1; i <= 10; i++) {
    sum += i;
}
System.out.println("Άθροισμα: " + sum);   // Άθροισμα: 55
```

Η παρένθεση έχει τρία μέρη, χωρισμένα με `;`:

1. **αρχικοποίηση** (`int i = 1`): εκτελείται μία φορά, στην αρχή·
2. **συνθήκη** (`i <= 10`): ελέγχεται πριν από κάθε επανάληψη· όταν γίνει
   `false`, ο βρόχος σταματά·
3. **ενημέρωση** (`i++`): εκτελείται μετά από κάθε επανάληψη.

Το βήμα δεν είναι υποχρεωτικά 1. Για τους ζυγούς από το 2 έως το 20 γράφεις
`for (int i = 2; i <= 20; i += 2)`, και για αντίστροφη μέτρηση
`for (int i = 5; i > 0; i--)`.

### Ένθετοι βρόχοι

Ένας βρόχος μέσα σε άλλον: για κάθε επανάληψη του εξωτερικού, ο εσωτερικός
τρέχει ολόκληρος. Έτσι φτιάχνεις, για παράδειγμα, έναν πίνακα
πολλαπλασιασμού:

```java
for (int row = 1; row <= 3; row++) {
    for (int col = 1; col <= 3; col++) {
        System.out.print(row * col + "\t");
    }
    System.out.println();
}
```

```text
1	2	3
2	4	6
3	6	9
```

## Ο βρόχος while

Ο `while` ελέγχει τη συνθήκη **πριν** από κάθε επανάληψη. Είναι κατάλληλος όταν
δεν ξέρεις από πριν πόσες επαναλήψεις θα χρειαστούν. Ένα κλασικό παράδειγμα
είναι το άθροισμα των ψηφίων ενός αριθμού:

```java
int number = 4096;
int digitSum = 0;

while (number > 0) {
    digitSum += number % 10;   // παίρνουμε το τελευταίο ψηφίο
    number /= 10;              // και το «κόβουμε»
}
System.out.println(digitSum);  // 4 + 0 + 9 + 6 = 19
```

Πρόσεξε ότι κάτι μέσα στον βρόχο πρέπει να αλλάζει τη συνθήκη (εδώ το
`number /= 10`). Αλλιώς ο βρόχος δεν τελειώνει ποτέ.

Ο **αλγόριθμος του Ευκλείδη** για τον μέγιστο κοινό διαιρέτη (ΜΚΔ) είναι επίσης
ένας `while`: όσο το `b` δεν είναι 0, υπολογίζεις το υπόλοιπο `a % b`, το `a`
γίνεται `b` και το `b` γίνεται το υπόλοιπο. Όταν το `b` μηδενιστεί, το `a` είναι
ο ΜΚΔ.

```java
int a = 84, b = 36;
while (b != 0) {
    int remainder = a % b;
    a = b;
    b = remainder;
}
System.out.println("ΜΚΔ: " + a);   // ΜΚΔ: 12
```

## Ο βρόχος do-while

Ο `do-while` εκτελεί πρώτα το σώμα και **μετά** ελέγχει τη συνθήκη, άρα τρέχει
τουλάχιστον μία φορά. Είναι ιδανικός για μενού και για επανάληψη ενός
προγράμματος «όσο ο χρήστης θέλει»:

```java
Scanner input = new Scanner(System.in);
String again;

do {
    System.out.print("Δώσε έναν αριθμό: ");
    int n = input.nextInt();
    System.out.println("Το τετράγωνό του είναι " + (n * n));

    System.out.print("Ξανά; (y/n): ");
    again = input.next();
} while (again.equalsIgnoreCase("y"));
```

## break και continue

- **`break`:** βγαίνει **αμέσως** από τον βρόχο.
- **`continue`:** παραλείπει το υπόλοιπο της **τρέχουσας** επανάληψης και πάει
  στην επόμενη.

```java
int sum = 0;
for (int i = 1; i <= 20; i++) {
    if (i % 4 == 0) continue;   // παραλείπει τα πολλαπλάσια του 4
    sum += i;
    if (sum > 30) break;        // σταματά μόλις το άθροισμα ξεπεράσει το 30
}
System.out.println(sum);        // 1+2+3+5+6+7+9 = 33
```

## Πίνακες

Ένας **πίνακας** (*array*) κρατά **πολλές τιμές του ίδιου τύπου** κάτω από ένα
όνομα. Κάθε τιμή έχει μια θέση, τον **δείκτη** (*index*), που ξεκινά από το
**0**.

```java
int[] scores = {72, 85, 64, 90};      // πίνακας με 4 στοιχεία
double[] prices = new double[3];      // 3 θέσεις, όλες 0.0 στην αρχή

System.out.println(scores[0]);        // 72, το πρώτο στοιχείο
scores[2] = 70;                       // αλλάζει το τρίτο στοιχείο
System.out.println(scores.length);    // 4
```

Τρία πράγματα που πρέπει να θυμάσαι:

- Ένας πίνακας είναι **συγκεκριμένου τύπου**. Σε έναν `int[]` δεν μπορείς να
  βάλεις `"πενήντα"`: το πρόγραμμα δεν μεταγλωττίζεται καν.
- Το **μέγεθός** του είναι **σταθερό**: αφού δημιουργηθεί, δεν μεγαλώνει.
- Οι θέσεις πάνε από `0` έως `length - 1`. Το `scores[4]` σε πίνακα 4 στοιχείων
  προκαλεί, όταν τρέξει το πρόγραμμα, `ArrayIndexOutOfBoundsException`.

Για να περάσεις από όλα τα στοιχεία, χρησιμοποιείς έναν `for` με δείκτη:

```java
double total = 0;
for (int i = 0; i < scores.length; i++) {
    total += scores[i];
}
System.out.printf("Μέσος όρος: %.2f%n", total / scores.length);
```

## Ο enhanced for

Όταν θέλεις απλώς να «διαβάσεις» κάθε στοιχείο με τη σειρά, ο **enhanced for**
(ή *for-each*) είναι πιο απλός, γιατί δεν χρειάζεται δείκτη:

```java
int[] grades = {78, 91, 66, 84, 70};
int total = 0;

for (int grade : grades) {     // «για κάθε grade μέσα στο grades»
    total += grade;
}
System.out.printf("Σύνολο: %d, μέσος όρος: %.2f%n", total, (double) total / grades.length);
```

```text
Σύνολο: 389, μέσος όρος: 77.80
```

Χρειάζεσαι όμως τον κλασικό `for` όταν θέλεις να **αλλάξεις** τα στοιχεία ή να
ξέρεις σε ποια θέση βρίσκεσαι.

Πρόσεξε και το `(double) total`: χωρίς αυτό, το `389 / 5` θα ήταν διαίρεση
ακεραίων και θα έδινε `77`. Και όπως ο Scanner της Εβδομάδας 4, έτσι και το
`printf` ακολουθεί τις ρυθμίσεις του υπολογιστή: με ελληνικές ρυθμίσεις τυπώνει
`77,80` αντί για `77.80`.

## Ερωτήσεις αυτοαξιολόγησης

<details>
<summary>1. Πόσες φορές εκτελείται το σώμα του for (int i = 3; i < 15; i += 3);</summary>

Τέσσερις φορές, για i = 3, 6, 9 και 12. Μετά το i γίνεται 15, και η συνθήκη
`i < 15` είναι `false`.

</details>

<details>
<summary>2. Ποια είναι η βασική διαφορά ανάμεσα σε while και do-while;</summary>

Ο `while` ελέγχει τη συνθήκη πριν από κάθε επανάληψη, οπότε μπορεί να μην
εκτελεστεί ποτέ. Ο `do-while` την ελέγχει μετά, οπότε το σώμα του εκτελείται
τουλάχιστον μία φορά.

</details>

<details>
<summary>3. Τι υπολογίζει ο αλγόριθμος του Ευκλείδη για a = 30 και b = 12;</summary>

30 % 12 = 6 → (12, 6)· 12 % 6 = 0 → (6, 0). Το b μηδενίστηκε, άρα ο ΜΚΔ είναι
6.

</details>

<details>
<summary>4. Σε έναν πίνακα int[] data = new int[5]; ποια είναι η τελευταία έγκυρη θέση;</summary>

Η `data[4]`. Οι θέσεις πάνε από 0 έως `length - 1`, δηλαδή από 0 έως 4.

</details>

<details>
<summary>5. Πότε προτιμάς τον κλασικό for από τον enhanced for;</summary>

Όταν χρειάζεσαι τον δείκτη: για να αλλάξεις τα στοιχεία του πίνακα, να
διαβάσεις δύο πίνακες μαζί, ή να ξέρεις σε ποια θέση βρίσκεσαι.

</details>
